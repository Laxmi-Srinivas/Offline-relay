# onya iPhone build

Preserved from ios-mvp `4cf48653759763549eb77ad14a6c3d4ff1957984` as a separate
iOS build target. The controller and CoreBluetooth lifecycle are retained.
Integration changes are the local protocol package path and display branding;
package and bundle IDs remain unchanged.

Run Flutter commands here and build/sign `ios/Runner.xcworkspace` on a Mac.
See [root instructions](../../README.md). Historical iOS documents refer to this
application under its original `apps/offline_relay` path; substitute this directory.

iPhone ? iPhone only. Plaintext application messages, explicit acceptance,
concurrent requests, helper availability and local notifications are preserved.
The chat back arrow closes the link. Android encryption and Report are not part
of this baseline; use non-sensitive demo messages.
